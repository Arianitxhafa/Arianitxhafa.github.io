03Full-stack web app · Job-match co-pilot2026

CareerPilot

Your job search, under control.

A job-application tracker for students entering the job market: every application on one Kanban board, the numbers that matter — and a co-pilot that scores your CV against each job post.

  • Job-match co-pilot: a unit-tested matcher scores your CV against a job post and lists missing skills; Claude-powered analysis is built in
  • Kanban pipeline with drag and drop, optimistic updates and Server Actions
  • Supabase Auth and Postgres Row Level Security — every user only ever sees their own data
  • Next.js 16
  • TypeScript

  • Tailwind CSS
  • Unit tests

04Multi-tenant SaaS · Invoicing2026

Faturo

Invoices that look sharp — and get paid on time.

An invoicing SaaS for freelancers and small businesses in Kosovo: clients, invoices with VAT, PDF downloads and a dashboard that shows exactly who still owes you. Try it with one click — no sign-up.

  • Multi-tenant workspaces with owner / admin / member roles; tenant isolation verified by end-to-end tests
  • Money done right: integer cents, VAT 18 / 8 / 0 %, discounts, server-recomputed totals and PDFs with embedded fonts
  • One-click demo seeds a year of realistic data in a single atomic batch and cleans itself up after 24 hours
  • Next.js 16
  • TypeScript
  • Postgres (Neon)
  • Drizzle ORM
  • Auth.js
  • E2E tests
